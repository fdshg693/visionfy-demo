# アプリの提供する機能

## 概要

画像処理をワークフローとして定義して、自動化できるアプリケーションです。

## 主な機能

- AIチャットと会話ができる
    - スレッドごとに会話を整理
    - 以下のツールをAIが利用可能
        - ワークフローのパラメータ取得

- ワークフローキャンバス
    - 処理ノードを動的に追加・編集・連結させることが可能
        - 処理ノードやコネクタは右クリックから削除可能
        - 各処理ノードは一つのAPIと対応していて、backendのAPIを呼び出して、そこで画像処理を実行

- ワークフローのスナップショットを保存・復元
    - 終了ノードをクリックすると、処理結果の画像を確認可能
    - 各ノードごとの処理結果も確認可能
    - ワークフロー全体をスナップショットとして保存可能
        - ワークフローの構造やパラメータを含む（画像は含まない）
        - 保存したスナップショットを読み込んで、ワークフローを復元可能
